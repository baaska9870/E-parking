1️⃣  LOCATION TRACKING ON MAP
   ──────────────────────────────────────────────────────────────────────

   What It Does:
   ✅ Automatically detects user's current location
   ✅ Shows blue dot marker with glow effect on map
   ✅ Displays accuracy circle (semi-transparent blue)
   ✅ Shows latitude/longitude in popup
   ✅ Updates automatically when user moves
   ✅ Works on mobile and desktop browsers

   Visual Elements:
   • Blue marker (20px) with white center dot
   • 3px white border with glowing shadow
   • Semi-transparent blue accuracy circle
   • Dashed border showing detection radius
   • Clickable for exact coordinates

   Technical:
   📍 Uses browser Geolocation API
   📍 Leaflet.locate() method
   📍 Real-time position tracking
   📍 Graceful fallback if permission denied

   User Permission:
   • Browser asks permission first time
   • User can allow/deny location access
   • Setting remembered for future visits
   • Can be changed in browser settings
